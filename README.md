# AcademiqOS - Data Sovereignty Framework for Modern Education

A modern, self-hosted operating system and data sovereignty framework designed for educational institutions. This project provides a static enterprise landing page and distribution hub for campus administration, digital classrooms, and secure data management.

## ✨ Features

*   **Self-Hosted Enterprise Core**: Run your entire educational ecosystem on your own hardware, ensuring 100% data control.
*   **Zero Cloud Lock-In**: No third-party tracking, no perpetual SaaS fees, complete vendor independence.
*   **Dual-Layer Architecture**: Seamlessly integrates campus-wide management with classroom-specific teaching tools.
*   **Enterprise-Ready Licensing**: Transparent licensing and support models for academic institutions.

## 🚀 Getting Started

Since this repository currently houses the **Phase 0.5 static landing page**, you can run it instantly using any static server or simple browser preview.

### Quick Setup

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/AcademiqOS/landing-page.git](https://github.com/AcademiqOS/landing-page.git)
    cd landing-page
    ```

2.  **View the landing page**
    Open `index.html` directly in your browser, or serve it locally using Python or Node:
    ```bash
    # Python alternative
    python3 -m http.server 8080
    ```
    Then open [http://localhost:8080](http://localhost:8080).
